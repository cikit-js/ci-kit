# 设计文档

本目录保存 ci-kit 的设计文档。每份文档描述一个能力的**为什么**和**怎么做**，实现代码以文档为准；文档与代码不一致时，先确认哪一方是过期的。

## 目录

| 文档 | 主题 | 状态 |
| --- | --- | --- |
| [roundtable/](roundtable/README.md) | 圆桌：为多个 AI 席位提供讨论空间 | 设计定稿，代码未实现 |

## 约定

- 一个能力一个目录，目录内 `README.md` 是索引，其余文件按主题拆分。
- 文档中的参数表是**契约**：代码里的字段名、默认值、报错行为必须与文档一致。
- 未定的问题集中放在各文档的「待定问题」一节，并标明默认取向；决定后同步删除该条目。
